# Personal Budget Manager


Desktop application for managing personal finances.
It allows users to track income and expenses, manage monthly budgets, and export financial reports to PDF.


## Features

* Add and manage income.
* Record and categorize expenses.
* Manage monthly budgets.
* View financial summaries.
* Export data to PDF.
* Support for multiple languages.


## Supported Languages

The application supports multiple interface languages.

Available languages:

* English
* Polish
* German


## Installation

Download the latest version from the **Releases** section.
Run the installer suitable for your operating system.



## Requirements

Supported operating systems:

* Windows
* macOS
* Linux



## Data Storage & Privacy

Personal financial data is stored locally on the user's device and managed by the application. The application does not collect, transmit, or share financial information with external services. Users remain in control of their own financial data.
